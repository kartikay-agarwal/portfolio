01 — Selected work

Systems I've designed, run and debugged

01 Infrastructure

HexoForge — a self-hosted platform stack

A bare-metal deployment platform I operate myself: Dokploy on Docker Swarm with Traefik, ingress through Cloudflare Tunnel, and a self-hosted NetBird mesh VPN. Authentik provides single sign-on (OIDC/SAML) across Vaultwarden, Forgejo, LiteLLM, Beszel and NetBird, with automated backups to MinIO and a Grafana + Loki + Promtail logging stack.

The interesting part is the failures: recovering from Docker network corruption with a full Swarm re-initialisation, fixing tunnel packet loss by forcing HTTP/2 transport, untangling NetBird DNS and ICE issues, and restoring email deliverability under DMARC enforcement.

  • Docker Swarm
  • Traefik
  • Authentik
  • NetBird
  • Cloudflare Tunnel
  • MinIO
  • Grafana / Loki
02 LLM / ML

LLM fine-tuning & serving pipeline

Fine-tuned a Gemma 4 12B model on ~530 call transcripts across an 8×H200 cluster using Unsloth and TRL, taking training loss from 2.56 to 0.22. Fine-tuned LoRA adapters are served through vLLM on a GH200 (96 GB) inference box with 3.5 TB of NVMe for model storage. I also evaluated H100 SXM vs GH200 for a 32B support-chatbot workload and tracked ARM/aarch64 tooling gaps (LLaMA-Factory as the Unsloth alternative).

  • PyTorch
  • Unsloth / TRL
  • torchrun
  • vLLM
  • LoRA
  • JSONL datasets
03 LLM evaluation

Mortgage-screening assistant & LLM observability

Prompt-engineered and evaluated a screening assistant for a US mortgage lender, iterating the system prompt against automated evaluation runs (an LLM judge plus an auto-grader) to fix rate-refusal, opt-out handling and suggestion-collapse failures. Traces flow into self-hosted Langfuse and PostHog, with Grafana dashboards over ClickHouse for debugging production behaviour.

  • Prompt engineering
  • LLM-as-judge
  • Langfuse
  • PostHog
  • ClickHouse
  • Grafana
04 Data platform

Hexo — marketing analytics on Appwrite

A Meta-ads analytics platform on self-hosted Appwrite: a redesigned schema (meta_insights, ad_creative, ad_summary), ingestion through the Meta Marketing API including video assets, and automated Excel report generation. When Appwrite 1.8.0's SDK mishandled equal filters, I worked around it with fetch-all plus in-memory filtering.

  • Appwrite

A shared Windows Server 2025 RDP host for a group of users, extended past the default two-session limit, with LDAP authentication through Authentik (pGina), monitoring scripts, and a migration that included repairing broken NTFS ACLs to recover user profiles.

A 3D data-center management game: rack and server placement on a grid, cabling with switches and patch panels, airflow and cooling, power and UPS, contracts, employees and an economy layer. Being rebuilt from scratch in Godot with entirely new code, with Steam as the target.

Cyberpunk desk clock

A desk clock built around an NXP FRDM-MCXN947 (dual Cortex-M33) and a DS3231 RTC, in an FDM-printed retro-futuristic enclosure. After weighing Nixie, VFD and 7-segment options, I moved from Nixie tubes (hard to source in India) to VFD tubes.
